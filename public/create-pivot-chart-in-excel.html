How to Create a Pivot Chart in Excel

Excel pivot charts are built from PivotTables. The chart updates when you filter or rearrange the connected table, making it useful for exploring grouped data.

Start with a clean Excel table

Place one field name in each column header and one record on each following row. Avoid blank columns, merged cells, and manual subtotal rows. Convert the range to an Excel Table when possible so newly added records are easier to include later.

Insert a PivotTable

Select a cell in the source table and use Insert > PivotTable. Confirm the source range, choose where to put the table, and select the fields you want to summarize. Place a category in Rows, an optional second category in Columns, and a numeric field in Values.

Set the right aggregation

Excel often defaults to Sum for numeric fields. Change the Value Field Settings when you need Average, Count, or another calculation. A misleading aggregation can make an otherwise good chart answer the wrong question.

Insert the PivotChart

Click inside the PivotTable and select PivotChart from the PivotTable Analyze tab. Choose a clustered column chart for category comparisons, a line chart for time series, or another chart type that keeps the comparison clear. Use the connected field buttons to filter the result.

Refresh after changing source data

After adding or editing records, use Refresh on the PivotTable or PivotChart. If the source was not an Excel Table, verify the PivotTable source range also includes the new records.

Check the PivotTable before relying on the PivotChart

A PivotChart inherits its values from the PivotTable. Before changing colors or moving labels, verify the summary itself: compare one large group, one small group, and the grand total with the source worksheet. If a result is too high, look for duplicated records or a subtotal row included in the source. If it is too low, check whether the value field is stored as text or whether a filter excludes records you intended to include.

Use a chart title that names the measure, category, and time period, such as “Sales by region and category — Q2 2026.” Bars work well for category comparison, while a line is usually better when the row field is a meaningful sequence of dates. A pie chart should be reserved for a small number of parts of one complete whole. The goal is to make a checked answer faster to understand, not to display every field in the workbook.

Make recurring Excel reports comparable

For a monthly or quarterly report, preserve the same field definitions, filters, calculation, and date grouping. A change in the chart can then be interpreted as a change in the data rather than a change in setup. Export the PivotTable with the chart if another reader needs to verify the figures. When the workbook contains confidential columns, remove them from the report copy before you share it.

Troubleshoot an Excel PivotChart that does not update

If new rows are missing, click inside the PivotTable and confirm its data source includes the expanded range. Converting the source to an Excel Table before building the pivot usually makes later additions easier to include. Refresh the PivotTable after editing the source, and check that filters or slicers have not hidden the new period. A chart connected to a stale pivot cache can look correct while showing yesterday’s data.

If the chart includes “(blank)” or unexpected categories, return to the source column and inspect empty cells, trailing spaces, and spelling variations. If Sum changes to Count, Excel may be treating some values as text; correct the source type and refresh. Do not manually edit a displayed pivot total to make the chart look right. Fix the records or configuration so the table and visual remain reproducible.

Before distributing the workbook, test one known category and the grand total, then save the reporting period and filter state with the file. These checks make the PivotChart a transparent output of the source rather than a disconnected graphic.
