What the workbook contains

The download is a zip package in the XLSX format. It has two worksheets. Source stores the header and every loaded data row. Pivot starts the table at cell A3. Each distinct row label appears once, in the order it first appears in the file, with the sum beside it. The last pivot row is Grand Total. The package also contains these parts: a pivot cache definition, pivot cache records, and a pivot table definition named PivotTable1. The cache has one record for each source data row, and the pivot table part points at that cache and at the Source range.

The on-page preview adds two count columns, Plain numbers and Ignored cells. Those counts stay on this page. They are not extra columns in the PivotTable. The Pivot sheet has the row label and the sum only. Search volume for this page has not been verified.

Worked example

Input header Region, Product, Amount. Rows: East Desk 10, East Chair 5, West Desk 7, West Lamp with a blank amount, west Desk n/a.

Use example rows chooses Region as the row field and Amount as the value column. East appears first and its plain numbers are 10 and 5, so the sum is 15. West appears next. Its plain number is 7, and the blank amount is left out, so the sum is 7. west is a separate label because the text is not West. Its amount is n/a, which is not a plain number, so that sum cell is blank. The grand total is 15 plus 7, which is 22. Three plain numbers are included, and two value cells are left out. The cache still has five records, one per source row, including the blank and the n/a. Product stays on the Source sheet and in the cache, and it does not create pivot rows on this build.

Row labels and plain numbers

The row field keeps the exact cell text. Letter case and spaces stay, and the field is not trimmed. East and east are two groups. East with a trailing space is a third group. A blank row label is one group whose label is empty. Labels are not sorted alphabetically. 01 in the row field stays 01, because that column is stored as text. The pivot cache stores those labels as separate shared items, and the Pivot sheet cells use that same list.

The value column is the only column parsed as numbers. A cell counts after trimming its ends when the remaining text is a plain number: an optional plus or minus, digits, an optional decimal point, and an optional exponent such as 1e2. The stored number is the numeric value, so 10.0 becomes 10, 010 becomes 10, and 1e2 becomes 100. Blank cells, n/a, $5, 5%, and 1,000 stay text in the cache and are left out of the sum. They are not treated as zero. A group whose value cells are all outside that rule has a blank sum, not a zero. Zero is written only when plain numbers add to zero, such as 1 and -1. Sums use JavaScript numbers, so 0.1 plus 0.2 can be stored as 0.30000000000000004.

Refresh-on-load flag

The pivot cache definition in this file leaves out the refresh-on-load flag. Cell A1 on the Pivot sheet reads: Browser sums. No refresh-on-load flag. The numbers on that sheet are the sums calculated in the browser before the download. A check that opens the file in desktop Excel was not run for this page. The two row dimensions page is a separate summary: it calculates in the browser and does not write these PivotTable parts.

CSV, XLSX, and limits

Paste CSV or choose a .csv, .tsv, or .txt file. The first non-empty record is the header. Quoted fields can contain the delimiter and doubled quotes. An unclosed quote stops the load with an error and no workbook. Automatic delimiter detection looks at the header line and chooses among comma, semicolon, tab, and pipe. CSV text is read as UTF-8. Completely blank records are skipped before the cache is built.

An .xlsx workbook is read on this page as Office Open XML. After it loads, the worksheet list shows every sheet named in the file, with the first sheet selected. Older binary .xls workbooks are not read; save them as .xlsx or CSV first. The reader uses the value stored in the cell. A formula contributes that stored value when the file contains one, and this page does not recalculate the formula. See Microsoft's file formats supported in Excel and the PivotTable overview.

Files over 10 MB, tables over 100,000 data rows, or tables over 1,000 columns stop with an error. A column name longer than 255 characters stops before a workbook is built, because an Excel PivotTable field cannot use it. The same column cannot be both the row field and the value column. If the value column has no plain number, the build stops and no file is offered. The browser keeps the table in memory only. There is no account, and the file is not sent to a server. You can inspect a sheet first in the CSV viewer.

Frequently asked questions

What is inside the downloaded workbook?

The file is an XLSX workbook with worksheets named Source and Pivot. Source holds the loaded rows. Pivot holds one row per distinct row label, in first-seen order, plus a Grand Total row. The package also contains a pivot cache definition, one pivot cache record per source data row, and a pivot table definition named PivotTable1.

Does the file set refresh on load?

The workbook leaves out the refresh-on-load flag. The sums on the Pivot sheet are the sums calculated in the browser. A check that opens this file in desktop Excel was not run.

Which value cells are included in the sum?

A value is included only when trimming its ends leaves a plain number. Blank cells, n/a, currency symbols, percent signs, and thousands separators are left out. They are not treated as zero. A group with no plain number has a blank sum. The grand total is the sum of the group sums.

Do East and east become one row?

No. The row field uses the exact cell text. East and east are different, and a trailing space stays part of the label. The row field is not trimmed. The value column is trimmed only for the plain-number check.

Can one column be both the row field and the value column?

No. Build PivotTable workbook stops with an error. Choose two different columns.

Is the spreadsheet uploaded?

No. The browser reads the file and builds the workbook on your device. Closing the tab clears the working table unless you downloaded the XLSX.
