About the site

Practical pivot-table and chart tools that run in your browser

Pivot Chart Maker is an independent educational website and free web tool for turning CSV and XLSX files into checked pivot tables and clear charts.

What Pivot Chart Maker is for

Pivot Chart Maker helps people explore spreadsheet data without starting from a blank workbook. The tool lets you upload a CSV or XLSX file, choose the fields that define a question, calculate a sum, average, or count, and inspect the resulting pivot table before turning it into a bar, line, or pie chart. It is intended for everyday analysis tasks such as checking sales by region, following monthly activity, comparing categories, and preparing a small visual for a report.

The site also publishes original how-to guides and worked examples. Those resources explain how to prepare a source table, choose fields, recognize common setup errors, and select a chart that communicates the result honestly. The aim is to make the calculation visible rather than to hide it behind a one-click graphic.

How the browser tool handles your spreadsheet

The interactive tool is designed to process uploaded spreadsheet data locally in the browser. Parsing, grouping, chart rendering, and export happen on the device used to open the page; the site is not designed to upload the spreadsheet contents to an analysis server. The current working rows remain in browser memory while the page is open, and refreshing the page clears that working session. Downloads are generated on the device.

Local processing does not remove the need to review a result. A chart can be misleading when headers are duplicated, amounts are stored as text, source data contains subtotal rows, or categories are too numerous. For that reason, the tool keeps the source preview and pivot table close to the chart so visitors can check the evidence before sharing an export.
