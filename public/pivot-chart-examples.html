Pivot Chart Example: Sales by Region and Category

Use this small retail sales dataset to build a pivot table and a clustered bar chart. The example keeps the setup simple while showing an analysis that is useful in a real report.

Download the example data

The CSV contains 12 sales records across four regions and three product categories. It is intentionally compact so you can inspect every source record before trusting the result.

Download the sales example CSV

Question answered

Which product category generated the most sales in each region? Create a pivot table with Region in Rows, Category in Columns, and Sales in Values using Sum. The resulting chart makes both the regional totals and category mix easy to compare.

What is in the sample CSV

The example has twelve rows: three product categories in each of four regions. Each record includes Region, Category, Sub-Category, Sales, Quantity, and Order Date. The small size is intentional. You can open the CSV in a text editor or spreadsheet and trace every value into the finished summary. That makes this a practice exercise in verification as well as chart creation.

Before building the pivot, inspect the source rather than assuming it is correct. The column names are unique, every row represents one sale record, and Sales is the measure to aggregate. There are no report title rows, merged cells, or pre-calculated totals. In a real export, those three issues are common sources of unexpected totals because a pivot tool can interpret them as ordinary records.

Configure the pivot table

Upload the file in the free tool, then select Region as the row field and Category as the column field. Select Sales as the value field and choose Sum. The table should show one row for East, West, Central, and South, one column for each category, and a total for each row. This setup answers two related questions: which category is strongest in each region, and which region has the largest total across categories.

Do not skip the table check because the chart is easier to look at. Compare a few cells against the source rows. East Technology, for example, comes from the East Technology record; the East row total is the sum of its three category values. The grand total is the sum of all twelve Sales values. If your output differs, first check the selected aggregation, then look for an accidental filter or a value field detected as text.

How to read the result

Technology is the largest category in every region in this example. The West has the highest Technology sales, while the East has the largest overall total. Verify those conclusions in the pivot table before using the chart in a presentation. The chart makes the pattern visible quickly: the category bars within each region reveal the mix, and the relative group heights suggest the regional total. The table gives the exact figures needed to test that impression.

The example is not a forecast and it does not prove a business cause. It is a compact illustration of the mechanics of a pivot chart. In a real sales review, you would add context such as the reporting period, market size, sales targets, returns, and whether categories have consistent definitions. A clear chart states what is measured and gives readers enough information to avoid drawing conclusions that the data does not support.

Try useful variations

After recreating the base view, change one setting at a time. Put Category in rows and Region in columns to make product comparison the primary view. Change Sales to Quantity to see whether the units ranking matches the revenue ranking. Use Order Date as the row field and group dates by month when a time trend is the real question. These small experiments show why the field choices matter: the same source file can answer several valid questions, but each chart should communicate only one of them.

Use a bar chart for this example because it compares categories across regions. A pie chart would not be a good fit because the categories are repeated for several regions, and a line chart would be less clear without a meaningful time sequence. The best chart is determined by the question and the structure of the pivot table, not by a preference for a particular visual style.

Export a result others can verify

When the table is correct, export the chart as a PNG for a slide or report. Export the pivot table as CSV or XLSX if another person needs to review the values. Include a title such as “Sales by region and category — sample data” so the audience knows the scope. Keeping the summary with the chart makes the analysis easier to reproduce and prevents a visual from being separated from its supporting numbers.
