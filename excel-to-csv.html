What Excel to CSV conversion does

This tool converts a single worksheet from an Excel .xlsx or .xls workbook into one UTF-8 CSV file. After upload, you select which sheet to export when the workbook contains more than one. Conversion reads the stored cell values that Excel last cached for display: what you would typically see in the cell after opening the file, not live re-evaluation of formulas against a full calculation engine in the browser. Numeric dates, formatted numbers, and text become plain text fields in CSV form. Formatting such as fill colors, fonts, borders, column widths, merged cell presentation, and conditional formatting rules are not carried over. Each run exports exactly one worksheet; other sheets remain in the workbook untouched until you convert them in separate passes. Processing is local to your browser without uploading the workbook to a conversion server. The UI shows a preview of the first twelve rows of the CSV text; the download contains all rows that were read from the used range of that sheet, subject to the same row and column limits as other tools on the site.

When to use this instead of Save As in Excel

Use in-browser conversion when you do not have Excel installed, you want a quick one-sheet UTF-8 CSV on another operating system, or you prefer not to email a workbook through unrelated desktop steps. It is appropriate when cached values in the file are trustworthy: you opened and saved the sheet in Excel recently, values are constants, or you accept that formula cells export whatever was last calculated and stored. It is not appropriate when you must guarantee fresh formula results after macro or external data changes without opening Excel, or when you need multiple sheets in one CSV file, because this tool never merges sheets. For CSV-only utilities such as transpose or merge, run Excel to CSV first, then upload the resulting CSV to those pages; they do not accept .xlsx directly. If your workflow needs formatting, pivot tables, or charts, keep the workbook format; CSV is for data interchange, not presentation.

Step-by-step workflow

Confirm the workbook is at most ten megabytes and that the target sheet's used area fits within one hundred thousand data rows and one thousand columns. Choose the .xlsx or .xls file and click Convert. The first sheet is displayed; choose another worksheet and click Convert again to export it. The reader walks the sheet's populated range, resolves displayed values for each cell, serializes rows using comma separators, and fills the preview with the first twelve lines of the CSV string. Scan the preview for sensible column splits, empty leading rows if the sheet had blank top margin, and formula cells that show zero or old dates suggesting stale cache. Download the CSV for the full export. Open in a text editor or import into your next tool with UTF-8 encoding specified. To convert another sheet, repeat with the same or a new upload; there is no batch all-sheets zip from this page. Save the CSV under a clear name indicating sheet name and export date if you manage many extracts.

Displayed values, formulas, and dates

Excel files often store both a formula expression and a cached result. This exporter uses the cached result path appropriate to the file format so cells appear as users last saw them in Excel, without invoking a full recalculation pipeline in JavaScript. That means an IF or VLOOKUP cell exports the last saved outcome, which might differ from what Excel would show after refreshing external links today. Constant cells export their literals directly. Date cells typically export as the displayed serial formatting Excel cached, which may look like a calendar string or a number depending on how the workbook was saved; downstream tools may need explicit date parsing. Empty cells produce empty fields. Cells with errors cached as error displays may export error text visible in the sheet. There is no option here to export formula strings instead of values. If you need formula text, copy from Excel's formula bar or use a specialized Excel feature. Boolean values become whatever string representation the reader obtains from the cell record.

Concrete conversion example

Imagine a small .xlsx sheet named Sales with cells A1:C2 where A1 is Item, B1 is Qty, C1 is Price, A2 is Apple, B2 is 10, C2 contains a formula multiplying quantity by a unit price with cached displayed value 45.50, formatted as currency in Excel but stored as display text 45.50 or a localized variant depending on cache. The CSV header row becomes three fields: Item, Qty, Price. The second row contains Apple, 10, and the displayed cached result, which may include currency symbols from the cell format. A blank row 3 outside the used range does not appear. If row 2 instead held a formula with no cached value in a damaged file, you might see an empty field or an odd token; repairing in Excel and re-saving fixes cache. The downloaded CSV uses commas between fields and quotes values containing commas.

Worksheet selection and range behavior

Multi-sheet workbooks require you to choose one worksheet per conversion. Hidden or very hidden sheets may still appear in the list if the reader enumerates them; sheets exceeding the row or column guards are rejected. Leading entirely blank rows and columns at the edge of the used range may still affect how many blank fields appear at the start of a row if the format stores a rectangular used range including blanks. After export, verify column alignment in the preview because merged cells in Excel can confuse rectangular reads: you may see values only in the top-left cell of a merged block with blanks in sibling columns that visually spanned in Excel. Charts, images, and shapes are skipped. Tables defined as Excel tables still export as cell values in the grid. For .xls legacy binaries, support covers the same conceptual behavior though very old files might fail parsing with an error message. One worksheet at a time is a deliberate scope limit, not a multi-select omission you can toggle on.

Limits, failures, and chaining to CSV tools

Files above ten megabytes fail early. Sheets with more than one hundred thousand rows or one thousand columns hit limits during read or write. Corrupt archives, password-protected workbooks without provided passwords, or unsupported encryption typically produce errors instead of partial CSV. Browser memory may struggle below theoretical limits on low-end devices. Output is UTF-8 CSV with comma delimiter and RFC-style quoting when fields contain separators or line breaks. After download, transpose can rotate the CSV including its first row as data; merge can append multiple CSV exports if each has valid headers and consistent row widths. Neither chained tool reads Excel natively. If merge reports duplicate headers, fix the CSV header line in an editor. If transpose widens beyond two thousand columns, reduce source rows or split the sheet before conversion. Recalculate important formulas in Excel before export when stale cache would cause wrong downstream analysis.

CSV format reference

CSV fields may contain commas or line breaks when quoted correctly. See the CSV format specification RFC 4180 for common conventions.

Frequently asked questions

Can I select a worksheet?

Yes. Convert once to load the workbook and select a sheet, then convert again to export it.

Are Excel formulas recalculated?

No. The converter uses stored cached results and does not recalculate formulas.

Does the CSV retain formatting?

No. CSV stores values as text rather than workbook formatting, charts or multiple sheets.
